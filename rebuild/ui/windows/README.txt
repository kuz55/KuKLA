KuKLA — переносимый клиент для Windows x64

1. Распакуйте все файлы архива в обычную папку на компьютере.
2. Запустите KuKLA.exe двойным щелчком. Установка GTK, Go и Node.js не требуется.
3. Создавайте локальные операции и редактируйте анкету на этом компьютере.

Это тестовая версия, а не подписанный установщик. Windows может предупредить
о неизвестном издателе. Используйте пакет только из доверенного источника.

Текущий клиент работает локально: он не подключается к серверу и не
синхронизируется с другими устройствами. Карта, задачи, группы, вход и другие
разделы ещё не реализованы. Не используйте эту версию для ответственных
спасательных операций без дополнительной проверки.

Локальная база и анкета хранятся в %LOCALAPPDATA%\KuKLA\Data\db\kukla.sqlite,
отдельно от папки программы, и не зашифрованы. Не заносите конфиденциальные
данные без мер защиты устройства. Удаление папки программы не удаляет базу.
