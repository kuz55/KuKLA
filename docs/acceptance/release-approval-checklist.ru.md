# Что согласовать перед выпуском KuKLA

**Статус:** проект перечня для согласования. Ни одно решение в этом документе не считается принятым. Документ не является юридическим заключением или разрешением на сбор реальных данных.

До письменного утверждения применимых правил и завершения проверок используйте только синтетические данные. Текущий PR #11 не разрешает эксплуатацию в реальных поисковых операциях.

## 2. Проверки, которые нужно завершить до реальных данных или production-выпуска

Это технические и операционные проверки, а не замена согласованию политики:

- [ ] Проверить на Windows фактическую запись, чтение и удаление токена в Credential Manager; проверить миграцию старого токена и отсутствие plaintext-fallback при ошибке хранилища.
- [ ] Провести такие же runtime-проверки на Linux с реальным Secret Service и пользовательской сессией D-Bus. CI уже проверяет компиляцию и создание Linux DEB, но не выполняет операции с реальным хранилищем.
- [ ] На staging пройти менеджерский acceptance-сценарий только с синтетическими профилями; проверить поисковую изоляцию, роли, аудит и отказоустойчивое поведение.
- [ ] Проверить фактическую production-конфигурацию PostgreSQL и резервных копий: шифрование, доступ, хранение и восстановление. Не указывать сроки хранения или целевые параметры резервного копирования без решения владельца.
- [ ] Проверить production-процедуры аудита и хранения данных на соответствие утвержденной политике; зафиксировать результаты и ответственных.
- [ ] Согласовать и проверить сценарии потери/восстановления связи перед любым полевым использованием.
- [ ] Для production-выпуска закрыть применимые задачи дорожной карты: security scan, backup/restore drill, наблюдаемость, план аварийного восстановления и подписание релизных пакетов. Tauri CI для Windows MSI и Linux DEB уже проходит; runtime-доступ к системным хранилищам и подписание релизов этим не подтверждены.

## 3. Вне текущего PR / отдельное решение о продуктовой готовности

Текущая работа не завершает весь roadmap и сама по себе не разрешает операционный выпуск. Для полевой/операционной системы отдельно остаются, среди прочего: мобильный клиент, регистрация устройств, синхронизация и разрешение конфликтов, GPS-переподключение, check-in и эскалации, SOS, уведомления, GIS-функции, офлайн-карты, закрытие поиска, архив и отчеты. macOS и мобильные проверки также не входят в текущую сборку.
