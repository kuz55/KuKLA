# Code of Conduct

## 🇷🇺 Наши правила

KuKLA — открытый проект, в котором должны быть комфортные условия для технических специалистов и людей с практическим опытом поисковой работы.

Участники обязуются:

- относиться друг к другу уважительно;
- обсуждать идеи и код, а не личности;
- принимать конструктивную критику;
- не допускать оскорблений, травли, дискриминации и угроз;
- не публиковать чужие персональные данные;
- не раскрывать секреты, учётные данные или чувствительные данные поисковых операций;
- добросовестно сообщать об ошибках и проблемах безопасности.

Поддерживать проект можно независимо от уровня опыта. Новичкам рекомендуется задавать вопросы и начинать с небольших задач.

## 🇬🇧 Our rules

KuKLA is an open project intended to bring together technical specialists and people with practical search-and-rescue experience.

Participants are expected to:

- treat others with respect;
- discuss ideas and code rather than people;
- accept constructive criticism;
- avoid harassment, discrimination, threats and personal attacks;
- never publish another person's private information;
- never expose secrets, credentials or sensitive search-operation data;
- report bugs and security issues responsibly.

People of all experience levels are welcome. New contributors are encouraged to ask questions and start with manageable tasks.

## Enforcement

Project maintainers may remove or edit comments, issues, pull requests or contributions that violate these rules. Serious or repeated violations may result in a contributor being blocked from participation in project discussions or contributions.
