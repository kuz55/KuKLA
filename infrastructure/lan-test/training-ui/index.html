KuKLA — учебный стенд

ТОЛЬКО ВЫМЫШЛЕННЫЕ ДАННЫЕ. Не использовать для реальных поисков.

Учебный интерфейс неполный. SMS не отправляются; офлайн-очереди и гарантированной доставки уведомлений нет.

Вход

Горячая линия: новое обращение

Пустое поле означает «неизвестно». После ошибки связи повторите ту же отправку, не создавая новое обращение.

Регистратор: очередь

    Карточка обращения

    Координатор: принять поиск

    Скопируйте ID поиска у регистратора. Действие доступно только допущенному координатору.

    Регистратор: назначение старшего на месте

    Скопируйте ID поиска и ID пользователя, показанный после его входа. Назначение действительно только после принятия.

    Старший на месте: приглашения

    Уведомления доступны только при открытии этого списка; это не доставка и не гарантия оповещения.

      Старший на месте: создать группу

      Кандидат должен быть участником этого учебного поиска. Временный способ подготовки — в инструкции стенда.

      Старший группы: приглашения

      Список обновляется вручную; доставка уведомлений не обеспечена.

        Старший на месте: назначить задачу

        Группа должна иметь принявшего назначение старшего. Срок вводится в часовом поясе этого устройства.

        Задачи группы

          Старший группы: отправить результат

          Только краткие вымышленные сведения. Задача считается завершённой после приёмки старшим на месте.

          Старший на месте: проверить результат

            Закрытие учебного поиска

            Старший на месте подтверждает готовность. Координатор закрывает поиск; исключение без подтверждения требует причины. SMS не отправляются.
