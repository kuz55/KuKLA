# SmartCam AI — Умный помощник камеры (CameraX + OpenCV 4.10 + Jetpack Compose)

Android-приложение камеры с анализом экспозиции и композиции в реальном времени (60 FPS превью, MVVM + Clean Architecture).

## Возможности
- **Базовая камера (CameraX 1.4.1):**
  - Аппаратное превью `PreviewView` с тап-фокусом и замером экспозиции (`AF/AE`).
  - Сохранение фотографий в высоком разрешении (`Pictures/SmartCamAssistant`).
  - Переключение основной и фронтальной камер + ползунок экспокоррекции `EV`.
- **Анализ экспозиции (OpenCV `calcHist` + `meanStdDev` по Y-плоскости Zero-Copy):**
  - Живая 256-корзинная гистограмма яркости с отображением времени кадра (мс) и частоты анализа (Гц).
  - Подсветка зон пересвета (красная диагональная **«Зебра»**) и глубоких провалов в тенях (голубая штриховка).
  - Умные текстовые подсказки с анти-дребезгом (гистерезисом).
- **Анализ композиции (OpenCV `Canny` + `HoughLinesP` + `Sobel Saliency`):**
  - Переключаемые сетки: **Правило третей**, **Золотое сечение + спираль Фибоначчи**, **Диагонали**.
  - Определение угла завала горизонта в реальном времени (предупреждение **«Выровняйте горизонт»** при наклоне **> 2°**).
  - Детекция доминирующего объекта в кадре и стрелка наведения к ближайшему узлу правила третей.
- **Режим отладки для эмулятора (`Debug`):**
  - Кнопка переключения сцен в правом верхнем углу (`Живая камера` / `Тест: Пересвет` / `Тест: Завал 6.5°` / `Тест: Объект и трети`) позволяет мгновенно проверить все алгоритмы OpenCV даже в эмуляторе без подключённой веб-камеры.

## Быстрый запуск готового `smart-camera-debug.apk`

### 1. В эмуляторе Android Studio
1. Запустите любой эмулятор (API 26–35, `x86_64` или `arm64-v8a` на Mac Apple Silicon).
   - Совет: в настройках AVD (`Camera -> Back Camera`) выберите `VirtualScene` (управление наклоном и обзором комнаты через `Alt + мышь` / `WASD`) или `Webcam0`.
2. Просто **перетащите файл `smart-camera-debug.apk` мышью на окно эмулятора**, либо выполните в терминале:
   ```bash
   adb install -r smart-camera-debug.apk
   ```
3. Откройте приложение **SmartCam AI** и разрешите доступ к камере.

### 2. На физическом Android-смартфоне
1. По USB с включённой *Отладкой по USB*:
   ```bash
   adb -d install -r smart-camera-debug.apk
   ```
2. Или скопируйте `smart-camera-debug.apk` в память телефона / Telegram («Избранное») и нажмите для установки.

### 3. Открытие проекта в Android Studio
Откройте папку `smart-camera` (или распакуйте архив `SmartCamAssistant-AndroidStudio-Project.zip`) через **File → Open** в Android Studio Ladybug / Meerkat (JDK 17+).
