# KuKLA Roadmap

This roadmap is intentionally community-driven. Priorities may change as technical and field requirements become clearer.

## Current foundation

- [x] Client-server architecture
- [x] Desktop client foundation
- [x] Mobile client foundation
- [x] Fastify API
- [x] PostgreSQL and Redis infrastructure
- [x] JWT authentication
- [x] Server-side RBAC
- [x] Search lifecycle
- [x] Tasks and task status
- [x] Audit/event log
- [x] GPS ingestion and track display
- [x] OpenStreetMap mapping
- [x] Mobile offline cache/queue foundation
- [x] Docker Compose deployment
- [x] Backup/restore tooling

## Next priorities

- [ ] Automated unit, integration and end-to-end test coverage
- [ ] CI pipeline for build, lint, tests and security checks
- [ ] Stronger authentication and session management
- [ ] Production-grade notification system
- [ ] Robust background GPS operation on mobile
- [ ] Offline-first synchronization conflict handling
- [ ] Improved operational map tools
- [ ] Better task assignment and field-status workflows
- [ ] Observability, structured logging and metrics
- [ ] Production deployment and upgrade documentation
- [ ] Independent security review
- [ ] Field acceptance testing with search teams

## Community research areas

- [ ] GIS/geospatial analysis
- [ ] Search-sector and grid planning tools
- [ ] Route and track analysis
- [ ] AI-assisted operational features, with human verification
- [ ] Communication resilience for areas with poor connectivity
- [ ] Accessibility and low-light field UX
- [ ] Hardware/GPS integration
- [ ] Data import/export and interoperability

## How to influence the roadmap

Open an Issue with the problem, user story, technical proposal or field scenario. Significant features should be discussed openly before implementation so that the community can evaluate operational value, security and maintainability.
